# Sales Analytics Dashboard

## Project Overview
This project analyzes online retail sales data to identify revenue trends, top-selling products, and country-wise sales performance.

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- SQL (SQLite)
- Power BI

## Key Features
- Data cleaning and preprocessing
- Sales revenue analysis
- Monthly revenue trend visualization
- Top 10 products by revenue
- Country-wise sales analysis
- Interactive Power BI dashboard with date and country filters

## Dataset
Online Retail dataset from the UCI Machine Learning Repository.

## Project Structure
- `src/` - Python scripts for data cleaning and analysis
- `reports/charts/` - Generated charts
- `Sales_Analytics_Dashboard.pbix` - Power BI dashboard

## Dashboard Preview
See `sales_dashboard.png` for a screenshot of the dashboard.

## How to Run
1. Install Python.
2. Install required libraries:
   `pip install pandas openpyxl matplotlib seaborn sqlalchemy`
3. Run the scripts in the `src/` directory in the appropriate order.
